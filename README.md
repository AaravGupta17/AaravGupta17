# Aarav Gupta

I like building things that are a little too low-level for a school project.

Most of what I work on sits somewhere around systems, machine learning, algorithms, and quantitative computing. I usually learn by picking something I don't fully understand and trying to build it from scratch.

### Things I've been working on

**[Ferrite](https://github.com/AaravGupta17/Ferrite)**  
A neural-network inference runtime written in C11. I built the tensor/runtime pieces, a hand-written ONNX parser, graph optimisations, memory planning, INT8/FP16/BF16 paths, and AVX2 kernels. It is mostly an exercise in understanding what frameworks normally hide.

**[AcousticLeakNet](https://github.com/AaravGupta17/SJWP_Research)**  
A research project for detecting and localising water-pipe leaks from acoustic signals. The data is generated from EPANET simulations and the model uses a 1D CNN with cross-channel attention to learn from two sensor signals.

**Quant / finance**  
I've been experimenting with market data, simulation, optimisation and quantitative models. I also worked on a Monte Carlo optimisation problem during a quant developer internship.

**Other stuff**
